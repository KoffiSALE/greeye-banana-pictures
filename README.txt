# GREEYE BANANA PICTURES Website

A first professional, responsive website concept for GREEYE BANANA PICTURES Ltd.

## Included
- Responsive one-page website
- User-provided GREEYE BANANA PICTURES logo
- About, Work, Services and Contact sections
- Mobile navigation
- Cinematic visual design using temporary stock photography

## Important
The email address and phone number in the first version are placeholders/working details and should be confirmed before publishing.
The film images are temporary web images. Replace them with your own posters, production stills and behind-the-scenes photographs.

## How to preview
Open `index.html` in a web browser.

## Next customization
Replace:
- temporary film images
- contact email
- social media links
- film descriptions
- company biography
- any placeholder information

Then upload the folder to your web host.
